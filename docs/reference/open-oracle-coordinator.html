OpenOracle coordinator reference

Implementation reference for OpenOraclePriceCoordinator in the documented source release. The compiled ABI is authoritative for signatures and tuple fields; deployed getters are authoritative for deployment-specific values. Cache freshness, pending-report presence, and staged-operation count are orthogonal observable conditions.

Durable coordinator predicates and outcomes

Report processing outcomes are events, not durable report states. Cache freshness, pending-report presence, and active-operation count are independent observations; a callback or recovery call can change more than one dimension in the same transaction.

Observable condition Authoritative reads Next boundary
Fresh cache isPriceValid(), cached price, settlement timestamp Immediate operation execution is eligible.
Stale cache with no pending report Pending report ID, request cost, active operation ID PriceRequested starts a report.
Pending report pendingReportId != 0 Only pendingReportSponsor may queue additional operations until callback or recovery clears the pending fields.
Recovery eligibility Nonzero pending report whose OpenOracle settlement timestamp is nonzero Precondition for one successful recoverSettledPendingReport() call; it is not a state produced by that call.
One or more active staged operations getActiveStagedOperationCount() and paged active IDs Each execution consumes one operation; a callback consumes only its bounded batch, so the count may remain positive.
Zero active staged operations Active count and pending settlement count are zero New staging may execute immediately with a fresh cache or create/join a pending report when the cache is stale.

Events

Setup and price-seeding events are SecurityPoolSet and RepEthPriceSet. Price lifecycle events are PriceRequested, PriceReported, PriceReportRejected, PendingReportRecovered, and PendingOperationRecoveryConsumed. Operation lifecycle events are StagedOperationQueued, StagedOperationDisputeStakedRepSnapshotted, and ExecutedStagedOperation. Every coordinator mutation also emits CoordinatorStateCheckpoint(reason, reportId, operationId, pendingReportId, pendingReportSponsor, pendingOperationSlotId, pendingReportMaxSettlementBaseFeeAttoEthPerGas, lastPrice, lastSettlementTimestamp, stagedOperationCounter, activeStagedOperationCount, pendingSettlementOperationCount). Preserve event order and block identity when reconstructing state.

Limits and deployment values

Value Meaning Authority
MAX_PENDING_SETTLEMENT_OPERATIONS = 4 Maximum number of staged operations auto-executed by one settlement callback; additional operations remain active for manual execution. Coordinator constant.
PRICE_VALID_FOR_SECONDS = 5 minutes Freshness window for the cached REP/ETH price. Source constant in OpenOraclePriceCoordinator.sol.
MAX_OPERATION_VALID_FOR_SECONDS = 5 minutes Maximum caller-selected operation validity window; expiry also includes coordinator settlement time. Source constant and staging guard.
OPEN_INTEREST_DIVIDER = 100 Divisor used in the open-interest component of the minimum WETH report size. Coordinator constant.
validForSeconds Positive operation validity window within the five-minute maximum. Caller input checked by the coordinator.
settlementTime, gas limits, and multipliers Determine report settlement, callback budget, minimum report size, and solvency thresholds. Immutable constructor values; deployed getters supply them; record chain, block, commit, and manifest hash.

The appendix contains the detailed mathematical and security record; deployment-specific values belong in the signed deployment verification report rather than being treated as universal protocol constants.

Machine-readable source

The structured coordinator schema is open-oracle-coordinator.json. It records the public ABI inventory, observable outcomes, event declarations, enum mappings, and parameterized entry points. The compiled ABI remains authoritative for tuple components and deployment-specific values; this page supplies reader-facing definitions and links to complete contract interactions.
