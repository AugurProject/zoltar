Zoltar, Statoblast, and Trading

Augur protocol documentation

Augur builds Zoltar, a forkable oracle for resolving questions, and Statoblast, the prediction-market protocol built on it. Trading exchanges Statoblast outcome shares, and OpenOracle supplies the REP prices Statoblast uses to check backing.
