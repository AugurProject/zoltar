Zoltar and Statoblast

Zoltar provides branching universes and universe-specific REP. Statoblast uses those universes to operate collateralized prediction markets with Yes, No, and Invalid outcome shares. Statoblast Trading is one exchange implementation built on those shares; other trading implementations can be built on top of Statoblast. OpenOracle supplies contestable REP/ETH prices for solvency-sensitive operations.

A fork lets users continue in selected child universes, but it does not copy ETH or guarantee full redemption in every branch. A child pool can remain impaired if too little collateral migrates and its Truth Auction cannot raise the difference.
