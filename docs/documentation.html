Zoltar and Statoblast

Zoltar provides branching universes and universe-specific REP. Statoblast uses those universes to run collateralized prediction markets with Yes, No, and Invalid shares. Statoblast Trading is an exchange for those shares, and OpenOracle supplies the contestable REP/ETH prices the protocol uses to check that REP still covers ETH obligations.
