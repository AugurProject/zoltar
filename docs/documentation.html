Zoltar, Statoblast, and Trading

Augur protocol documentation

Zoltar provides branching universes and universe-specific REP. Statoblast uses those universes to run collateralized prediction markets with Yes, No, and Invalid shares. Trading is an exchange for those shares, and OpenOracle supplies the contestable REP/ETH prices the protocol uses to check that REP still covers ETH obligations. Augur is the project that builds these protocols; its Augur Statoblast and Statoblast Trading apps are the web interfaces to Statoblast and Trading.
