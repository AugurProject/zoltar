Liquidate an unsafe vault

Transfer unsafe allowance and its target-funded free-REP award into a non-liquidatable liquidator vault using the correct fresh-price path.

Verify the target

Inspect the target vault's allowance, locked and unlocked REP, pending liquidation state, and pool lifecycle. Calculate health using current protocol values. Do not depend on a cached UI label when the execution transaction will use fresher state.

Prepare the liquidator

Use a distinct liquidator vault that remains non-liquidatable after accepting the transferred allowance and award. The liquidator does not supply REP or ETH liquidation principal: the complete bonus-bearing award comes from the target's free REP. A maximum request records any unfunded residual allowance as bad debt; it does not draw an external backstop payment.

Stage on the correct price path

  1. Preview the transferable allowance, complete target-funded free-REP award, and any residual bad debt from a maximum request.
  2. Stage the operation through the pool's price coordinator.
  3. If the cached REP/ETH price is fresh, the staged operation executes immediately and no report is created.
  4. If the price is stale, the requester sponsors the OpenOracle bounty and initial position; track the report and correction window through settlement.
  5. Re-evaluate target and liquidator state before any later execution.

Execute and check the result

Verify the coordinator's execution result on either the immediate fresh-price path or after a valid report settles. Confirm the target's free REP funded the complete award, the transferred allowance and ownership reached the liquidator, a maximum request recorded only the untransferred residual as bad debt, and pool conservation properties still hold. A failed callback is not a successful liquidation.

Recover or repeat

If execution conditions changed, use the staged-operation recovery path. If the target remains unsafe, calculate a new bounded chunk from current state; do not replay stale parameters. The liquidation explanation owns the economic rationale and formulas.
