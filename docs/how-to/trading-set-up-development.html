How-to guide

Set up Trading development

Build and run

  1. From the repository root, confirm dependencies with test -d node_modules. If they are missing, run bun install --frozen-lockfile && bun run setup.
  2. Run bun run trading:compile, bun run trading:test, and bun run trading:ui:build.
  3. Start bun run app:serve:trading, then open http://localhost:4163/?simulate=1&genesis=yes for the browser-local simulator. Configure the Trading UI lists the Trading scenarios. The setup works when the tests pass and the simulator page loads.

To run the standalone UI in Docker instead, complete the repository-root setup first, then from ui/trading:

docker network inspect zoltar >/dev/null 2>&1 \
  || docker network create zoltar
docker compose up --build --force-recreate

Open http://localhost:4163/#/market. On Windows, use ui/trading/start.bat to start Compose.

Test transactions against an external node

To exercise the contracts on a local Anvil node, follow Use local Anvil; for script and integration tests, Deploy for script and integration tests covers bun run trading:deploy:local.

Other commands

See the root package scripts for the Trading check, contract coverage, and gas report commands.

After a change that alters what the UI shows, run bun run docs:screenshots -- --app trading to recapture the documentation screenshots.
