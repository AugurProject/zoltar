How-to guide

Configure the Trading UI

Use this guide to choose between live and simulated mode and to point the Trading UI at the network and RPC you need.

Choose a mode

  • With no mode parameter, the UI reads live RPC and wallet state.
  • ?simulate=1 boots a browser-local simulator with seeded contracts and balances. Add &simScenario=deployed for a SecurityPool with no trading pool, &simScenario=baseline for a chain without Statoblast or Trading contracts, or leave it out for the default trading-funded scenario with one funded market. A banner labels the page as a simulation.

Set up Trading development lists the commands that serve the UI.

Select a network and RPC

Open Settings in the header. Choose the RPC network, and optionally enter a Fallback RPC URL and select Save RPC. A custom RPC must use HTTPS, or HTTP on a loopback address, and must serve the selected chain. It is used only until a wallet is connected on the selected chain; after that, the wallet's own RPC serves reads and transactions.

The UI then checks the RPC chain and the core contracts, and derives the Trading factory and router addresses for that network. If either is not deployed, the deployment screen opens; Deploy the Trading contracts covers it. Once both are found, the Markets tab opens. The configuration reference describes what the client derives and checks.
