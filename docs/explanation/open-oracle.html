OpenOracle integration

OpenOracle supplies a fresh REP/ETH price for solvency-sensitive Statoblast operations. It does not decide market truth; local escalation and Zoltar remain responsible for truth and branching.

Integration boundary

Each security pool has a coordinator. A user requests or executes a pool operation through that coordinator. When its cached price is fresh, the coordinator can use it immediately; when it is stale, the coordinator stages the operation behind a new OpenOracle report. Report-level checks determine whether the callback is accepted and the price cache updated; operation-level pool checks then determine whether each queued operation succeeds or emits an execution failure.

The coordinator converts settled WETH and REP amounts into a REP/ETH price using lastPrice = amount2 × 1018 ÷ amount1. Addresses, limits, gas costs, report parameters, and deployment wiring are release-specific; consult the coordinator reference for the selected deployment.
