## Development report

Run `bun run duplication:report` (or `bun scripts/duplication-report.mts`). It emits JSON to stdout, has no CI failure threshold, and never updates its baseline. Redirect output outside the worktree if desired. `source` contains production-only groups; `tests` contains test/fixture groups, including any mixed source/test groups. New groups have `baseline: false`; removed groups appear in `resolvedBaseline`.

This is an exact function-body detector with a minimum of 100 TypeScript scanner tokens. It ignores whitespace/comments but preserves names and literals. It does not detect renamed, partial or semantic clones. Only TypeScript-family files are inspected. Git supplies tracked and nonignored untracked paths, excluding deleted worktree entries while retaining unstaged rename destinations. Maintained TypeScript tooling under `ui/coreShared/build`, `ui/trading/build`, and `solidity/ts/coverage` stays in scope; dependencies, vendored/generated directories, build output, coverage output, JavaScript output and named contract artifacts are excluded. The report is deliberately development-only, without adding a runtime dependency or package installation.

The initial 21 fingerprints were reviewed by inspecting their source bodies and callers. Retention is a scoped disposition, not a claim that future consolidation is unjustified:
