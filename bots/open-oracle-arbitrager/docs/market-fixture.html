OpenOracle market fixture

Historical evidence is not a launch guarantee. Execution requires an available arbitrager, a robust reference market, and a correction that remains profitable after actual execution costs.

At Ethereum block 25,600,852 on 2026-07-24, the pinned executable REP/WETH fixture constructed two hypothetical reports around a 2,121.147070719536334508 REP midpoint. Both reports used the base-fee-derived minimum WETH side of 0.817262744792307693 WETH, a 0.1% reporter fee, a 1% protocol fee, and the 1% Uniswap V3 REP/WETH pool. The sell-REP scenario used 2,227.204424255513151233 REP, exactly 5% above the midpoint; the buy-REP scenario used 2,015.089717183559517782 REP, exactly 5% below it. Gas was deliberately set to 0 WETH so the result isolates pre-gas market and fee economics.

Under only those two constructed report scenarios, the fixture produced pre-gas results of -0.255235735754674523 WETH for the sell-REP correction and -0.626254311426940506 WETH for the buy-REP correction. Both modeled paths were unprofitable before gas; the result does not generalize to another report size, deviation, fee schedule, pool, block, or gas cost.

Run bun ./scripts/check-market-fixture.mts to reproduce the calculations. Set OPEN_ORACLE_ARCHIVE_RPC_URL to also replay the pinned block and quotes. Operators must repeat the analysis against current executable liquidity before taking risk; this dated fixture does not establish that a profitable corrector exists now.
